**AfroChat** is an AI-powered chat platform that brings the latest language models together in one place. It offers a public AI console for seamless interactions and an enterprise solution for businesses to customize AI models to their specific organizational needs.

### Key Features & Architecture

- **Multi-Model Orchestration**: Seamless access and interaction across state-of-the-art language models.
- **Enterprise Customization**: Tailored AI model fine-tuning and deployment for businesses.
- **High-Performance Backend**: Built with Express, MongoDB, OpenAI API, AWS SES, AWS S3, Redis, WebSockets, Docker, Kubernetes, RabbitMQ, Kafka, ElasticSearch, GraphQL, Prisma, Mongoose, and Cloudflare.
- **Role**: Backend Developer.
