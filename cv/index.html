Projects

  • The Geometry of Dormant Defection (Latent Sleeper Agent Linear Probes)

    Mechanistic interpretability research and 28-layer probing replication suite investigating layer-wise linear probe dynamics for detecting latent sleeper agents and dormant backdoors in large language models. GitHub Code Research Article Zenodo Preprint

    • Layer-Wise Activation Probing: Designed and evaluated linear probes across all 28 transformer layers of Qwen2.5-Coder-1.5B-Instruct to trace where deceptive policies linearly separate from aligned representations.
    • Mid-Layer Concentration Discovery: Discovered that peak linear separability concentrates in mid-layer representations, formulating trigger-agnostic defensive monitors that catch backdoors without inspecting outputs.
    • Tech Stack: Python, PyTorch, Hugging Face Transformers, Linear Probes, Mechanistic Interpretability, Qwen2.5-Coder.
